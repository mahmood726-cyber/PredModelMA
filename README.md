# PredModelMA

Browser-based prediction model validation meta-analysis with PROBAST.

## Methods
- **C-statistic pooling** — logit transformation, delta-method SE, REML/DL
- **O:E ratio pooling** — log transformation, REML/DL
- **PROBAST** — 4-domain risk of bias (Participants, Predictors, Outcome, Analysis)

## Plots
- Forest plot (c-statistics with pooled diamond)
- Forest plot (O:E ratios)
- PROBAST traffic light + bar chart

## Examples
- Framingham Risk Score (10 validations)
- SCORE2 (7 validations)
- QRISK3 (6 validations)
